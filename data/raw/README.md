# Restricted data location

Do not commit any NEDIS workbook or derived data to this repository.

An authorized researcher may place the customized extract here as:

```text
NEDIS_custom_extract.xlsx
```

Alternatively, set the `NEDIS_RAW_XLSX` environment variable to a secure local path. The workbook must contain the `EMIHPTMI` worksheet and the columns listed in `docs/variable_dictionary.md`.
